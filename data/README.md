# Datos

Los CSV no se suben al repo por su tamaño. Descárgalos de Kaggle y colócalos en `data/raw/`:

| Archivo en `data/raw/` | Dataset en Kaggle | Uso |
|---|---|---|
| `spotify-tracks-dataset.csv` | *Spotify Tracks Dataset* — maharshipandya (114k canciones, 125 géneros) | Entrenamiento: 8 géneros latinos |
| `tracks_features.csv` | *Spotify 1.2M+ Songs* — rodolfofigueroa | Fuente de las canciones peruanas |

Ambos traen las mismas características de audio de la API de Spotify (que Spotify dejó de ofrecer a apps nuevas en noviembre de 2024, por lo que estos datasets son hoy la única forma práctica de obtenerlas).
